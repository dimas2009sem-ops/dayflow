# DayFlow — уведомления на телефон

Эта версия использует Web Push. Сервер хранит подписку телефона и проверяет задания каждые 15 секунд. В указанное время он отправляет push-уведомление, поэтому уведомление может прийти даже когда DayFlow закрыт.

## 1. Установить зависимости

```bash
npm install
```

## 2. Создать VAPID-ключи

Самый простой способ после установки зависимостей:

```bash
npx web-push generate-vapid-keys
```

Скопируй `publicKey` и `privateKey` в `.env` по образцу `.env.example`.

## 3. Запустить

```bash
npm start
```

Открой приложение через HTTPS на телефоне. Для телефона нужен HTTPS-домен; обычный `http://localhost` подходит только для тестирования на компьютере.

## 4. Включить уведомления

В DayFlow открой «Настройки» → «Нагадування про завдання» → «Увімкнути сповіщення» и разреши уведомления.

После этого задания синхронизируются с сервером. Когда приложение закрыто, сервер продолжит проверять расписание и отправлять push.

### Важно
- Для iPhone/iPad открой HTTPS-версию DayFlow и добавь её на экран «Домой». После этого разреши уведомления.
- Для Android можно использовать HTTPS-версию в Chrome и установить приложение на главный экран.
- Сервер должен работать постоянно. Если сервер выключен в момент задания, push не отправится.
