DAYFLOW — PUSH-УВЕДОМЛЕНИЯ

В архиве уже есть версия DayFlow с:
- первым выбором языка: Українська / Русский / English;
- сохранением выбранного языка;
- уведомлениями по времени заданий;
- синхронизацией заданий с push-сервером;
- Service Worker для получения уведомлений при закрытом приложении.

Чтобы push реально приходил на телефон, сервер из папки server должен быть запущен постоянно и доступен по HTTPS.

Быстрый запуск сервера:
1. cd server
2. npm install
3. npx web-push generate-vapid-keys
4. создай файл .env по образцу .env.example и вставь VAPID public/private keys
5. npm start

После публикации сервера открой DayFlow по HTTPS на телефоне, установи его на главный экран и в Настройки включи «Напоминания о заданиях».
