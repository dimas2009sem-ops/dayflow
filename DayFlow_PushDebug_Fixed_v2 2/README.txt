DayFlow — исправление Push-уведомлений и диагностика

В архиве папка server/ для Render.

Что добавлено:
- Кнопка «Отправить тест» в настройках для проверки доставки Push без ожидания задания.
- Подробные логи синхронизации и ошибок отправки в Render Logs.
- Планировщик допускает двухминутное окно после времени задания, чтобы не пропустить уведомление из-за задержки таймера.

Развёртывание:
1. Замените файлы проекта актуальными файлами из архива (сохраните свои VAPID значения в Render Environment).
2. Убедитесь, что Root Directory у Render соответствует папке server, если сервис настроен на запуск из server/; если Dockerfile используется из корня, настройка должна соответствовать текущему render.yaml.
3. Дождитесь статуса Live.
4. Откройте DayFlow на iPhone, зайдите в Настройки и нажмите «Отправить тест».
5. Если тест не приходит, проверьте Render → Logs. Ищите [test-push], [sync], [reminder].

Важно: Web Push требует интернет. PWA не может гарантировать локальные уведомления без интернета, если она не нативно установлена с локальным планировщиком.
