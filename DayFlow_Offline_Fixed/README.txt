DAYFLOW — ПОЛНАЯ ПОДГОТОВКА К ТЕЛЕФОНУ

В архиве лежит готовая PWA-версия с Push-уведомлениями.

ПОЛЬЗОВАТЕЛЬСКИЙ ПУТЬ:
1. Разместить папку server на HTTPS-хостинге.
2. Настроить VAPID-ключи.
3. Настроить постоянное хранилище для server/data.
4. Открыть HTTPS-ссылку на телефоне.
5. Установить DayFlow на главный экран.
6. Разрешить уведомления.
7. Создать задания со временем.

Для iPhone: Safari → Поделиться → На экран Домой → открыть установленный DayFlow → Настройки → Уведомления → Включить.
Для Android: Chrome → Установить приложение / Добавить на главный экран → открыть DayFlow → Настройки → Уведомления → Включить.

ВАЖНО: файл index.html сам по себе не может гарантировать push после закрытия. Нужен HTTPS и постоянно работающий сервер из папки server.
