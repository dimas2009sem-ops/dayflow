# DayFlow — полноценное PWA-приложение с Push

Эта папка — готовая веб-версия DayFlow: её можно разместить на HTTPS-домене и установить на телефон как постоянное приложение.

## Что уже готово
- PWA manifest и иконки для установки на главный экран.
- Service Worker для получения Push-уведомлений.
- Сервер Web Push с VAPID.
- Хранение подписок и заданий в `data/push-data.json`.
- Проверка расписания каждые 15 секунд.
- Часовой пояс телефона учитывается при отправке.
- Поддержка украинского, русского и английского.

## Офлайн-режим и уведомления на iPhone
- После первого успешного открытия приложение кэширует оболочку и основные файлы, поэтому интерфейс может открываться без сети.
- Задания, профиль и история по-прежнему хранятся в `localStorage` на этом устройстве. Офлайн-изменения не синхронизируются с сервером до восстановления сети.
- **Ограничение iOS PWA:** Web Push требует интернет-доставки. Обычная PWA на главном экране iPhone не предоставляет надёжного универсального API для планирования локальных уведомлений, которые сработают без сети. Этот ZIP улучшает офлайн-доступ, но не превращает Push в локальные уведомления.
- Для уведомлений, заранее запланированных на самом iPhone и работающих без сети, понадобится нативная iOS-оболочка (например, Capacitor + `@capacitor/local-notifications`) и сборка через Xcode.
- Чтобы кэш обновился после публикации, обнови приложение при подключённом интернете. Данные задач не очищаются при обновлении кэша.

## Важно про сервер
Сервер должен работать постоянно. Для реальных уведомлений не используй обычный `localhost` и не открывай `index.html` через `file://`. Нужен HTTPS-адрес.

Для постоянной работы нужен хостинг с постоянным процессом и постоянным диском. В конфигурации `render.yaml` выбран платный Render Starter, потому что бесплатные сервисы могут засыпать и тогда уведомления будут пропускаться.

## Локальная проверка
```bash
npm install
npx web-push generate-vapid-keys
```
Создай `.env` из `.env.example`, вставь ключи и укажи email:
```env
PORT=3000
VAPID_PUBLIC_KEY=...
VAPID_PRIVATE_KEY=...
VAPID_SUBJECT=mailto:you@example.com
```
Затем:
```bash
npm start
```

## Публикация
Самый простой путь — GitHub → Render.
1. Создай приватный репозиторий GitHub и загрузи содержимое папки `server`.
2. В Render создай Web Service из этого репозитория.
3. Используй `Dockerfile`.
4. Добавь переменные `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`.
5. Включи постоянный диск для `/app/data`, иначе подписки могут потеряться после перезапуска.
6. После деплоя проверь `https://ТВОЙ-ДОМЕН/api/health` — должен вернуться JSON с `ok:true`.
7. Открой `https://ТВОЙ-ДОМЕН/` на телефоне.
8. В настройках DayFlow включи уведомления и разреши их.

## Установка на iPhone
1. Открой HTTPS-ссылку в Safari.
2. Нажми «Поделиться».
3. Выбери «На экран Домой».
4. Запусти DayFlow с иконки.
5. Открой настройки DayFlow → уведомления → включи.
6. В системном окне iOS разреши уведомления.

Push на iPhone для веб-приложения работает после добавления сайта на экран «Домой».

## Установка на Android
1. Открой HTTPS-ссылку в Chrome.
2. Выбери «Установить приложение» / «Добавить на главный экран».
3. Запусти DayFlow с иконки.
4. В настройках DayFlow включи уведомления и разреши их в Android.

## Важное ограничение
Уведомления зависят от того, что сервер доступен в момент задания. Если хостинг остановлен, push не будет отправлен. Поэтому для режима «как настоящее приложение» используй постоянно работающий сервер и постоянное хранилище.
