# DayFlow: офлайн-режим и уведомления на iPhone

## Что исправлено в этой версии

- Service Worker кэширует главную страницу, manifest и иконки. При потере сети переход на главную страницу использует кэш. Остальные GET-ресурсы кэшируются по мере загрузки. API-ответы не кэшируются.
- Дата «сегодня» вычисляется по локальному времени устройства, а не по UTC — это предотвращает смену дня в приложении не в полночь по местному времени.
- Текст в настройках честно сообщает, что Push требует интернета, а локальные задачи доступны офлайн после первой загрузки.

## Что работает офлайн

Задачи, профиль и история хранятся в `localStorage`, поэтому после успешной первой загрузки они доступны без сети на том же устройстве и в том же установленном веб-приложении. Пока сети нет, синхронизация с сервером Push не проходит; при следующем подключении сохранённые задачи синхронизируются при открытом приложении.

## Что не может гарантировать PWA на iPhone

Этот проект остаётся PWA. Web Push не доставляется без сети, а Service Worker не может надёжно просыпаться по произвольному расписанию для отправки локальных уведомлений. Поэтому нельзя обещать офлайн-напоминания, если интернет полностью отключён.

## Путь к локальным уведомлениям без интернета

Для этого нужен нативный контейнер iOS, например Capacitor, с плагином `@capacitor/local-notifications`. Приложение должно запланировать уведомления на устройстве при создании/изменении/удалении задачи и пересоздавать расписание при запуске. Сборка и установка iOS-версии требуют Xcode на Mac и разрешения уведомлений от пользователя.
